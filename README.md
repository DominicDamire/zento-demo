# Zento demo

Zento is a multi-tenant booking app for salons, barbers and spas. Clients book a service, a professional and a time slot; owners manage a calendar, waitlist, messages, loyalty cards and stock.

**Live demo:** https://dominicdamire.github.io/zento-demo/

- Everything in the demo is **invented**: businesses, people, prices, bookings and messages. The page makes no network requests and stores nothing.
- It is a small static re-creation of the key flows (client booking; owner calendar, waitlist, messaging, loyalty, stock), styled after the app. It is not the app itself.
- The Zento source code is **private** and is not in this repository.
- Photos are AI-generated placeholders. The font is Schibsted Grotesk (SIL OFL, see `assets/OFL.txt`).
